# Budbud Hindi F.P. School — Website

A beautiful, fully responsive **static website** for **Budbud Hindi F.P. School**, a government primary school established in **1953** in Budbud, Sukdal village, Galsi-I block, Purba Bardhaman district, **West Bengal**.

The school offers education from **Pre-Primary to Class 5** under the **West Bengal Board of Primary Education**.

## ✨ Features
- Modern, animated, mobile-first responsive design
- Hero with the school gate, animated stats counters & scroll-reveal effects
- Sections: About, What We Offer, Principal's Message, Photo Gallery, Contact
- **"Email Us"** form that opens the visitor's mail app pre-filled to the school inbox
- Pure HTML/CSS/JS — no build step, no dependencies

## 📁 Structure
```
index.html            # the whole site
assets/css/style.css  # styles + animations
assets/js/main.js     # nav, reveals, counters, email form
assets/img/           # school photographs
render.yaml           # Render static-site blueprint
```

## 🚀 Run locally
Just open `index.html` in a browser, or serve it:
```bash
python3 -m http.server 8000
# visit http://localhost:8000
```

## ☁️ Deploy
- **Render:** New → Static Site → connect this repo. Publish directory `.` (config in `render.yaml`).
- **GitHub Pages:** Settings → Pages → deploy from the `main` branch root.
